# 划词提问（ask-ai）

给 teach 教学工作区的 lesson 加上「划词就地提问」。选中正文任意一段，浮出气泡，点开右侧抽屉就能问 —— 不用切回编辑器找 agent。

**lesson 文件本身没有被改过一行。** 组件由本地服务在返回 HTML 时动态注入，所以以后新生成的课自动就有这个能力。

---

## 快速开始

```bash
git clone https://github.com/OlivaFute/aksanything.git
cd aksanything
```

手要先做两件事（**两件都能在页面上点**，不必手改 JSON）：

1. **指定工作区** —— 课程目录的绝对路径（就是 `lessons/` 所在的那一层）。
   启动后打开 <http://127.0.0.1:8899>，首页顶部就有一条「课程目录」，填进去点绑定，**保存即生效、不用重启**；
   设置页 <http://127.0.0.1:8899/config> 的「〇、工作区」是同一个入口。
   填 `lessons/` 本身或更深的分类目录也可以，会自动上溯到工作区根。
2. **配一个 AI 通道** —— 三选一，见下方 provider 表。在设置页填，或改 `ask.config.json`。仓库里的 `providers.api.apiKey` 是**空的**，默认设计成读环境变量，这样 key 永远不会进 Git：

```bash
setx DEEPSEEK_API_KEY "sk-你的key"     # Windows，设完要重开终端
```

> **工作区会写在 `ask.config.local.json`，不是 `ask.config.json`。**
> 前者是本机覆盖层，已在 `.gitignore` 里；后者是要提交的中性模板，`workspace` 永远留空。
> 页面上改工作区只动本地文件 —— 否则你每 commit 一次，就把自己的 `D:\...` 路径推给别人了。

配好之后双击 **`askanything.bat`**，或手动：

```bash
cd "<工具目录>"
node ask-server.mjs
```

然后开 <http://127.0.0.1:8899>，进入任意一课，划词即可。

服务做三件事：

1. 托管整个教学工作区（lesson 里的 `../assets/lesson.css` 这类相对路径原样可用）
2. 返回 HTML 时注入 `ask-ai.js`
3. 提供 `/api/ask` 流式接口，把上下文拼好再发给 AI

**服务哪个工作区**按优先级取：`--workspace` 参数 > `ask.config.local.json` > `ask.config.json` > 工具目录的上一级。启动时临时指定：

```bash
node ask-server.mjs --workspace "D:\Project\我的课程"
```

工作区没配对时首页会显示一条醒目的提示（而不是只列出一片空白），并在那里给出输入框。

## 课程分类

`lessons/` 下的**一级子目录就是一个分类**：

```
lessons/
  0001-three-algorithms-overview.html   ← 顶层，归入默认分类
  线性代数/
    0001-xxx.html                       ← 归入「线性代数」分类
    MISSION.md                          ← 该分类专属的目标（可选）
  物理/
    0001-yyy.html                       ← 归入「物理」分类
```

**加新项目只需要新建一个文件夹**，不用改代码。首页会自动按分类分组。

| 约定           | 说明                                                                                       |
| ------------ | ---------------------------------------------------------------------------------------- |
| 分类展示名        | 默认用目录名；想显示别的名字，在 `ask.config.json` 的 `categories.labels` 里映射，如 `{"linear-algebra": "线性代数"}` |
| 顶层课程的展示名     | 由 `categories.defaultLabel` 决定（默认「未分类」）                                                  |
| 分类专属 MISSION | 分类目录里放 `MISSION.md`，会**优先**于工作区根目录那份                                                     |
| 课程 id        | 相对 `lessons/` 的路径（如 `线性代数/0001-xxx.html`），前后端约定用这个                                      |

**资源路径不用管**：课程移到子目录后 `../assets/lesson.css` 本来会失效，但服务在返回 HTML 时  
会自动把这类 `../` 相对路径重写成站点绝对路径（`/assets/lesson.css`）——**移动文件后不必手工改引用**。

提问时的上下文也做了区分：**只详列当前分类的课程**，其它分类仅点名。这样课程变多之后，  
目录不会把上下文吃光。

## 划词的四个动作

选中正文里任意文字，气泡会浮出四个动作：

| 动作        | 行为                                        |
| --------- | ----------------------------------------- |
| **解释这个词** | 就地弹出**可拖动卡片**：标题是你选中的词，正文是它的定义。不进抽屉、不打断阅读 |
| **解释这段**  | 打开右侧抽屉，深入浅出把这段讲清楚                         |
| **引用**    | 把选中的这一段挂到提问框的**引用区**（可累积多段，也能逐条移除）        |
| **新建问题**  | 新开一个划词追问任务，左侧 tab 里多一个                    |

### 卡片可以层层往下钻（树状）

在**卡片正文里再划词**，点「解释这个词」，会从当前卡片的右下角**长出一张子卡片**，父卡片保持不动。  
标题栏左侧的色条和 `└` 标记表示层级（第 1 层暗红、第 2 层墨绿、第 3 层赭黄）。

- 最多同时保留 5 张卡片，超出时会自动关掉最旧的
- **关闭父卡片会连同它的所有子卡片一起关**（树状语义）
- `Esc` 一次收起当前所有卡片

于是可以一路「景深 → 清晰度 → 弥散斑 → …」钻下去，每一层的来源都清楚可追溯。

### 卡片上的三个动作

| 按钮       | 作用                                                                                               |
| -------- | ------------------------------------------------------------------------------------------------ |
| **深入解释** | 用另一套提示词生成**详细版**（`prompts.defineDeep`）：物理含义、关键公式逐项解释、与本课数据挂钩的例子、常见误解。生成后按钮变「返回简版」，可随时来回切，两个版本都留着 |
| **复制**   | 复制卡片正文                                                                                           |
| **转入追问** | 把这页内容搬进右侧抽屉，作为一次问答继续深挖                                                                           |

简版只用当前章节做上下文（快），详细版会带整课全文（够全）。

### 划词范围

**正文、AI 的回答、定义卡片里的文字，全都可以划选** —— 在抽屉的回复里划一段、或在卡片里划一个词，同样能触发这四个动作。等于可以顺着 AI 的回答一路追问下去。

唯一的例外是卡片的标题栏（它是拖动把手，保持不可选以免和拖动冲突）。

从 AI 回答或卡片里划词时，请求会**标出出处**（「来自你之前给出的定义卡片，不是课程原文」），这样模型不会在课程正文里找不到这段话而困惑。相应地，这类划词没有「所在段落」这层上下文——那是正文专属的。

## 追问任务（左侧 tab）

抽屉最左侧是一列竖向 tab，每个 tab 是一个独立的追问任务，各自持有：

- 自己的引用列表（由「引用」按钮累积）
- 自己的对话历史
- 自己的编号（右上角红点表示这个任务已经问过内容）

点 **+** 或气泡上的「新建问题」新建任务。这样同一课里冒出来的几摊问题不会混在一条对话里。

## 配置页

打开 <http://127.0.0.1:8899/config>

可以在这里指定工作区（「〇、工作区」，写入 `ask.config.local.json`）、切换 AI 线路、填写 API Key、调整上下文策略、直接编辑三条提示词。**保存后立即热生效**（端口改动需重启），除工作区外的配置写回 `ask.config.json`。

工作区不写 `ask.config.json` 是刻意的：那个文件要提交，而工作区路径只对这一台机器成立。

安全约定：API Key **只存在于服务端进程内存里**，页面上只显示掩码（形如 `sk-a1b2****c3d4`）；提交时保留掩码即表示「不修改」。配置接口同样要求 token。

## 三条提问线路

不同动作走不同的提示词，都能在配置页里改：

| 动作    | 用哪条提示词            |
| ----- | ----------------- |
| 解释这个词 | `prompts.define`  |
| 解释这段  | `prompts.explain` |
| 自由追问  | `systemPrompt`    |

`prompts.explain` 已刻意**不再要求**回答必须关联上下文——重点放在把选段本身讲透。上下文仍然会随请求带给模型，只是不再强制它往「本课结构」上靠。

`systemPrompt` 是**三种模式共用**的，所以措辞必须保持中性：原先的「优先结合所在章节」「主动指出关联位置」已弱化为「不要为了显示关联而强行关联」，并补了一条仲裁规则——**具体模式的【要求】与通用要求冲突时，以更具体的那个为准**。否则一份 system 会和各模式自己的设定打架。

## 三条 AI 线路

改 `ask.config.json` 里的 `provider`，或启动时加 `--provider xxx`。

| provider  | 说明                             | 需要什么                                                                                                  |
| --------- | ------------------------------ | ----------------------------------------------------------------------------------------------------- |
| `api`     | DeepSeek 官方 API（默认）            | 去 platform.deepseek.com 注册，新账号送 500 万 token。把 Key 填进 `providers.api.apiKey`，或设环境变量 `DEEPSEEK_API_KEY` |
| `browser` | 浏览器桥接，驱动 chat.deepseek.com 网页版 | 完全免费。首次会弹出浏览器，扫码登录一次，登录态存在 `.cache/browser-profile`                                                   |
| `local`   | 本地模型 / 任意 OpenAI 兼容服务          | 默认指向 Ollama 的 `http://127.0.0.1:11434/v1`                                                             |

浏览器桥接首次登录：

```bash
node ask-server.mjs --login
```

浏览器会打开，扫码登录后 Ctrl+C 退出即可，之后提问就直接复用登录态。

## 提问时带什么上下文

四层全部自动收集，面板顶部会显示实际带上的是哪几层。

| 层  | 内容                     | 来源            |
| -- | ---------------------- | ------------- |
| L1 | MISSION 摘要（你在做什么、为什么学） | `MISSION.md`  |
| L2 | 课程目录（全部 lesson 标题）     | 扫描 `lessons/` |
| L3 | 本课标题 + 章节列表 + 当前阅读位置   | 页面 DOM        |
| L4 | 整课正文（含表格、图注、公式）        | 服务端读文件        |
| 局部 | 选中原文 + 所在段落全文          | Selection API |

默认 `lessonMode: "full"` 会带上整课正文 —— 你的 lesson 只有 12KB，整篇约 2~3k token，一次提问成本可以忽略，但 AI 能自动关联课内其它章节。想省 token 就改成 `"section"`。

**例外：「解释这个词」默认只带当前章节**（`context.defineLessonMode`，默认 `section`）。它是个轻量查询，塞整课正文只会拖慢响应；但当前章节照样带上，这样定义能对齐课内的用法和具体数字。想让它与其它模式一致地带全文，把这项改成 `full` 即可。

想先看看究竟发了什么给 AI：

```bash
node ask-server.mjs --dry-run
```

## 提问记录会被自动保存

每次问答都会追加到 `questions/<课号>-qa.md`。

**这样下次 `/teach` 时 agent 读得到你在哪句话卡过**，下一课可以针对性补，而不是重复讲你已经懂的。这是把网页里的即时问答接回 teach 的 learning-records 闭环。

## 常见问题

**首页是空的 / 说「还没有课程」？**

工作区没指对。首页顶部那条「课程目录」就是入口：填上 `lessons/` 所在的那一层（例如 `D:/Project/我的课程`），点绑定，**立刻生效不用重启**。

工作区没配对时，连课程自己的 `../assets/lesson.css` 也会 404（它从工作区读），所以课程页会掉样式 —— 这不是样式文件坏了，是找错了地方。

注意设置页的样式**不依赖工作区**，那种情况下它照常正常显示。

**一定要用 `http://127.0.0.1:8899` 打开吗？**

建议是。原因有三条，任一条都够：

1. `file://` 页面的 origin 是 `null`，请求本地服务会撞 Chrome 的 Private Network Access 预检，各浏览器行为不一致
2. `file://` 下浏览器读不到文件系统，**列不出课程目录**
3. 服务端注入意味着新生成的 lesson 自动生效，你不用记得去加 script 标签

如果确实要保留双击打开的习惯，跑一次 `node ask-server.mjs --inject`，它会把 script 标签写进现有 HTML。代价是 `file://` 下拿不到完整课程目录，只能带当前课的上下文（其余功能照常）。

**提问报错说找不到输入框？**

浏览器桥接没登录。跑 `node ask-server.mjs --login` 扫码登录一次。

**网页改版后桥接失效？**

`ask.config.json` 里 `providers.browser.selectors` 可以覆盖选择器，不用改代码。把新的 CSS 选择器填进去重启即可。

**端口被占用？**

`--port 9000` 换一个。

**为什么要校验 token？**

`localhost` 不是私密地址 —— 任何网页都能向 `127.0.0.1` 发请求。服务启动时生成随机 token 注入页面，每个 `/api/ask` 请求都要带，避免你的本机变成一个对全网开放的免费 AI 代理。同时服务只绑 `127.0.0.1` 并校验 Host 头，挡掉 DNS rebinding。

**API Key 会不会泄露到页面？**

不会。Key 只在服务端进程里，永不下发到浏览器。页面拿到的只是一个临时 token。

**代理（Clash）相关？**

`api.deepseek.com` 国内可直连，一般不需要代理。Node 的 fetch 不读系统代理，若你的网络必须走代理，请用 TUN 模式或让 Clash 放行直连。反过来要确认 Clash 的 bypass 列表包含 `127.0.0.1`，否则本地请求会被代理接管。

## 浏览器桥接的实测细节（改版时看这里）

这部分是实际跑通时测出来的，DeepSeek 改版后按此排查。

| 现象                | 原因                                                    | 处理                                                                                 |
| ----------------- | ----------------------------------------------------- | ---------------------------------------------------------------------------------- |
| 回答里混进模型独白         | 页面上「思考过程」和「正文」是**两个独立的 `.ds-markdown` 容器**            | 已锁定正文容器 `ds-assistant-message-main-content`；思考阶段只显示「正在思考…」                         |
| 回答抓一半就结束          | 早期版本用「停止按钮」判断生成状态，但实测 `[class*=stop]` 类选择器**一个都命中不了** | 改为「正文文本连续 4 秒不变化」判断结束（实测生成期间每 0.5 秒都有新增，不会误判）。阈值在 `ask-server.mjs` 的 `stable >= 8` |
| 公式变成 `\n𝜆\nλ` 重复 | KaTeX 同时渲染了可见版本和隐藏的 MathML 源码，`innerText` 把两份都取了      | 抓取时统一改写成 `$...$` LaTeX 源码，交给前端 KaTeX 渲染                                            |
| 输入框找不到            | 首选选择器 `textarea#chat-input` 已失效，但 `textarea` 可行       | 靠选择器列表按序回退，无需改代码                                                                   |
| 提示找不到 chrome.exe  | `PLAYWRIGHT_BROWSERS_PATH` 没指到工坊内的内核目录                | server 和 selftest 都会自动探测 `.cache/ms-playwright`                                    |

改选择器只需编辑 `ask.config.json` 的 `providers.browser.selectors`，**不用动代码**。

**公式显示不出来？**

回答里的公式会还原成 LaTeX（`$...$`）交给 KaTeX 渲染，KaTeX 走 CDN（jsdelivr）。离线或 CDN 不可达时原样显示 `$...$` 源码，不影响阅读。想彻底离线：把 KaTeX 的 js/css/字体下到 `assets/`，再改 `ask-ai.js` 里 `KATEX_VER` 附近的加载地址。

## 目录结构

工具本体和**工作区是分离的**：代码跟着工具走，课程内容留在工作区。

```
<工具目录>\                     ← 工具本体
  askanything.bat              双击启动
  ask-server.mjs               本地服务（零 npm 依赖）
  ask.config.json              中性配置模板（要提交，workspace 留空）
  ask.config.local.json        本机覆盖层（已 gitignore）：工作区指向这类本机信息
  selftest.mjs                 自检脚本
  LICENSE / README.md / PROMPTS.md   许可证与文档
  assets/
    ask-ai.js                  划词提问组件（注入到每个页面）
    katex/  pdfjs/             公式渲染 / PDF 渲染（已本地化，离线可用）
  node_modules/                playwright（仅浏览器桥接需要）
  .cache/                      运行时自动生成，可以随时整个删掉（已 gitignore）
    browser-profile/           桥接登录态
    ms-playwright/             Chromium 内核（首次用桥接时按需下载）
    shots/                     自检截图

<工作区目录>\                   ← 工作区（纯课程内容）
  MISSION.md / RESOURCES.md    学习目标与资源
  lessons/                     课程 HTML
  reference/                   速查文档
  questions/                   自动累积的提问记录
  learning-records/            学习记录
  assets/
    lesson.css / quiz.js       teach skill 自己的组件
```

**工作区路径**由 `ask.config.local.json` 的 `workspace` 决定（首页与设置页都能改，保存即生效），
也可用 `--workspace "路径"` 临时覆盖 —— 命令行优先级最高。查找顺序见「快速开始」。
换一个工作区只改这一处，工具代码完全不用动。

组件也按归属分流：`/assets/ask-ai.js` 和 `/assets/katex/*` 由**工具目录**提供，
其余 `/assets/*`（`lesson.css`、`quiz.js`）从**工作区**读 —— 所以工作区的 `assets/` 始终是干净的课程组件。

`browser` provider 依赖 `playwright`（可选依赖，已装在 `node_modules`）。只用 `api` 或 `local` 的话不需要它。
